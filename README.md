# Ely Delaney website preview

Staging copy of `ElyDelaney_Website_2026`, published to GitHub Pages so pages can be
checked on a phone during the brand guide rebuild.

**This is a preview, not the source of truth.** The working files live in the private
`@Claude` workspace. Never edit here. Edits here are overwritten on the next sync.

Rebuild with `build-site-preview.py` in the website folder, then commit and push.

Excluded from this copy on purpose: internal working docs (`*.md`), backups (`*.bak`),
the `Inputs/` folder of third-party competitor screenshots, and the `Landing Pages/`
funnels.

`robots.txt` disallows all crawlers and the root redirect is marked `noindex`.
